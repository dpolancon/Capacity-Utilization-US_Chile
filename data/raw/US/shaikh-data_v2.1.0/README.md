# Shaikh Data — full dataset download

These data have been reconstructed for research transparency and education. They may lag official revisions and should not be treated as an authoritative or real-time source. For decisions of record, defer to the original sources named in each series' provenance record.

## Contents

- **Shaikh Capitalism Data** (`rscd/`): Replication & 1860–2025 extension of Shaikh (2016) Capitalism
- **Measuring the Wealth of Nations** (`rmwnd/`): Replication & 1948–2024 extension of Shaikh & Tonak (1994)

Each dataset folder contains:

- `csv/` — one tidy CSV per series (`year` + one column per subseries).
- `xlsx/` — the same series as a one-sheet Excel workbook.
- `parquet/` — the same series as Parquet.
- `data_dictionary.csv` — every series + subseries with units and source.
- `CITATION.cff` — how to cite the dataset.

Downloads are CSV + XLSX + Parquet. For full per-series provenance, see the
site's Explore page (each series ships a downloadable provenance record).
