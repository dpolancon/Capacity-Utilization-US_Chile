# Chile BOP Binding Data Release v1.1

This is the frozen modelling and report input for the versioned academic-paper branch of `CL_BOP_BINDING`.
It joins audited Chile macroeconomic, distributional, gross-capital, RER, and WBOP series.

The source-of-truth wide and long files are byte-identical copies of `chile_bop_binding_v1`.
Version 1.1 completes the variable dictionary for the sequential integration-order audit and
explicitly identifies gross non-residential capital as a contextual variable excluded from the
promoted import--machinery VECM.

The wide file is the sole input to S30–S99. The long file is supplied for audit and visualization.
No credentials are included. See the provenance and SHA-256 manifests for reproducibility.
