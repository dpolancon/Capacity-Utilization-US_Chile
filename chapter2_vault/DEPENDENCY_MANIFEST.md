## Code → Artifact routing

The arrow above is coarse by design: it says the econometric object flows through the scripts
into `output/` and then into the paper, but not *which* script produces *which* figure or
table. That edge is recorded at the granularity of the individual artifact in:

**[[C06-ARTIFACT_ROUTING_REGISTRY]]** — `chapter2_vault/05_codes_implementation/`

It carries the curated Chapter 2 paper-facing lineage (artifact → producing script at
`file:line` → input data → consuming section), the known routing defects, and a pointer to the
generated edge ledgers at `output/artifact_routing/`, which are regenerated by
`codes/COMMON_S00_artifact_routing_scan.py` across all 301 scripts.

Consult C06 before changing any script's output path, and re-run the scanner afterwards.

## Reverse: "If I modify X, what breaks?"

Not yet written for the theory chain above. For the empirical layer, the reverse direction is
already answerable: `output/artifact_routing/artifact_routing_reverse.csv` maps each artifact
back to its producing script(s) and flags artifacts with none.
